PROYECTO PERSONAL CLOUD-PDF
plataforma web en la nube que permite subir archivos PDF, 
guardarlos en un servidor y luego abrirlos o descargarlos desde cualquier lugar, 
ya sea desde un celular o una laptop, usando solo internet.
Funciona como un Drive personal
¿Que lenguajes se uso?
Python es un lenguaje de programación que se usa mucho para crear servidores porque es simple y fácil de leer.
Flask es una herramienta (framework) que se instala en Python y sirve para crear páginas web y manejar peticiones, 
como subir archivos o mostrar información.
